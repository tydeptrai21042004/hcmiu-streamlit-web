# CALF Weather Forecast — Lightweight Streamlit UI

This is the corrected Streamlit app for the lightweight export produced by the notebook.

## Recommended upload

Upload the full ZIP generated by the notebook:

```text
CALF_weather_light_export.zip
```

The app will import these files together:

```text
data/weather.csv
results/input.npy
results/pred.npy
results/true.npy
results/metrics.npy
results/sample_indices.npy
scaler/weather_scaler.npz
metadata.json
onnx/*.onnx                 optional
```

## Important fixes

- Uses `scaler/weather_scaler.npz` from the same notebook run instead of refitting a wrong scaler.
- Uses `metadata.json` to set the correct default `seq_len=336` and `pred_len=96`.
- Supports `sample_indices.npy` for compact/lightweight result subsets.
- Automatically clears old result/scaler files before importing a new lightweight export ZIP.
- Adds buttons to clear stale results or all imported files.
- Supports optional ONNX deployment, but saved result visualization works without ONNX.

## Local run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## What to demo

For a stable demo, use **Step 1 → Upload** with `CALF_weather_light_export.zip`, then open **Step 3 → Saved results**.

Use **Step 2 → Forecast** only when you have uploaded a compatible ONNX model. Demo forecast is only a UI sanity check and is not CALF.
